# Contribuir com o Ritmo

Abra uma issue para descrever um problema ou propor uma mudança. Para erros, inclua navegador, sistema, passos para reproduzir e resultado esperado. Não publique backups com registros pessoais, credenciais ou dados de terceiros.

1. Crie uma branch a partir de `main`.
2. Faça uma mudança com escopo claro.
3. Execute `npm ci` e `npm test`.
4. Para alterações de interface, confira celular estreito, teclado e foco visível.
5. Para alterações em `dist/`, incremente a versão do cache em `dist/sw.js`.
6. Abra um pull request explicando problema, solução e verificação.

Mudanças na agenda, persistência ou importação devem preservar o histórico existente. Atualize testes quando a regra de negócio mudar. Não adicione backend, rastreamento ou dependências sem explicar a necessidade na proposta.

Para conteúdo de saúde e treino, forneça a fonte e diferencie evidência de sugestão prática. Uma mídia precisa mostrar a variante prescrita e manter canal e link. Não envie cópias de vídeos ou imagens sem autorização de uso.

Ao contribuir, você concorda em disponibilizar sua contribuição original sob a licença MIT do projeto. Preserve as licenças de materiais de terceiros.
